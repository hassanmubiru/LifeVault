# LifeVault

A production-oriented Flutter application that helps people securely collect, organize, search, and recover important personal information.

LifeVault is a hybrid personal archive combining local-first document access, powerful local search, and optional encrypted cross-device synchronization.

## Stack
- Mobile: Flutter/Dart with Material 3
- Backend: StreetJS (TypeScript) - no Express/NestJS/Fastify
- Database: PostgreSQL
- Search: Typesense (cloud) + local full-text search
- Storage: SQLite (local), protected file storage
